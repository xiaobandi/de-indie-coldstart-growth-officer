# 使用示例

技能：**排期**（`wf-indie-coldstart-scheduling`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/schedule_plan.py --pool examples/input/pool.json --start 2026-09-29 --days 7
```

**真实输出**：

```console
节奏：每平台每日1条　时段基线：2026.09-baseline　池键名：pool
| 日期 | 周 | 时间 | 平台 | 标题 | 类型 |
|---|---|---|---|---|---|
| 2026-09-29 | 二 | 19:00 | 小红书 | 通勤保温杯实测 | 图文 |
| 2026-09-29 | 二 | 12:00 | 抖音 | 3 秒看懂保温原理 | 短视频 |
| 2026-09-29 | 二 | 08:00 | 公众号 | 冬季补水专题 | 长文 |
| 2026-09-30 | 三 | 19:00 | 小红书 | 办公室喝热水指南 | 图文 |
| 2026-09-30 | 三 | 12:00 | 抖音 | 保温杯开箱 | 短视频 |

共排 5 条，跨度 7 天
```

> 按平台错峰时段自动排期，避免同一账号短时间连发

> **注意**：排期表是**建议**：热点突发时人工插单优先级应高于本表。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/schedule_plan.py --pool /path/to/your-data/pool.json --start 2026-09-29 --days 7
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/schedule_plan.py --pool examples/input/pool.json --start 2026-09-29 --days 7 || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。

---

## 质量自检（交付前必过）

- [ ] 同一天同一平台不重复排
- [ ] 各步产出按顺序衔接，链路无断点
- [ ] 缺料时显式停下来问，未用假设填补
