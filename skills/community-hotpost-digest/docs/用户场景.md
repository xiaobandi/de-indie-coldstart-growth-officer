# 用户场景

按「谁 → 什么情况下 → 说什么 → 得到什么 → 注意什么」组织。每个场景都能照着跑一遍。

---

> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · 出海冷启动获客官的日常用法

- **角色**：出海冷启动获客官
- **触发时机**：需要「社区热帖摘要」这件事有结果的时候
- **他会说**：`用 community-hotpost-digest 帮我热帖摘要`
- **需要准备**：热帖来源（链接 / 导出 / 用户粘贴内容）
- **拿到什么**：热帖摘要表 + 候选选题池
- **容易踩的坑**：热帖评论区往往比正文更有洞察，别只摘正文

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 community-hotpost-digest 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 热帖来源（链接 / 导出 / 用户粘贴内容） | ✅ | 缺失会导致输出不可用 |
| 赛道关键词 | ⬜ | 有则更好 |
| 时间窗口 | ⬜ | 有则更好 |

## 场景三 · 边界情况（重要）

这几条写清楚做不到什么，比列一堆能力更有用：

- 不抓取需登录或有版权限制的内容；来源由用户或平台连接器提供
