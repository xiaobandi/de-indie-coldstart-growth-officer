# 使用手册

技能：**痛点-卖点匹配**（`painpoint-sellingpoint-match`）　·　L1 原子技能　·　v1.0.0

---

## 一、环境要求

| 项 | 要求 |
|---|---|
| Agent 平台 | WorkBuddy / ChatGPT / DeepSeek Harness / Kimi Work / 豆包工作中任一 |
| Python | 3.8+（**仅当本技能自带脚本时需要**；纯对话使用不需要） |
| 第三方依赖 | 无（纯提示词技能） |
| 网络 | 无强制要求；Excel/图片类处理在本地完成 |

## 二、安装

### 2.1 目录放置（推荐）

```bash
cp -r painpoint-sellingpoint-match ~/.workbuddy/skills/          # WorkBuddy / 通用
```

### 2.2 各平台差异

| 平台 | 方式 | 注意事项 |
|---|---|---|
| WorkBuddy | 放到 `~/.workbuddy/skills/` | 支持自动触发，也可显式点名 |
| ChatGPT | 上传 zip | 需账号支持 Skills |
| DeepSeek Harness | `新建技能 安装:<repo-url>` | 需要仓库可访问 |
| Kimi Work | 上传 zip / 放目录 | **不会自动调用**，必须显式点名技能 |
| 豆包工作 | `新建技能 安装:<repo-url>` | 触发词识别依赖 description 质量 |

### 2.3 安装后自检

```bash
# 在技能库根目录执行（技能目录内没有 tools/）
python3 tests/run.py
```

校验项：目录名与 `name` 一致、只使用标准字段、正文不含平台专有工具名、触发词中英双语且信息量足够。**任一项不通过，技能在部分平台会静默不加载。**

## 三、快速上手

### 3.1 纯对话方式（零安装）

```text
用 painpoint-sellingpoint-match 技能：<把你的材料贴进来>
```

## 四、参数总表

### 4.1 输入字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 痛点清单 | ✅ | 缺失会导致早退或输出不可用 |
| 产品/服务说明 | ✅ | 缺失会导致早退或输出不可用 |
| 目标人群 | ⬜ | 提升质量，缺失不阻塞 |
| 竞品对照 | ⬜ | 提升质量，缺失不阻塞 |

### 4.2 触发词

| 语言 | 触发词 |
|---|---|
| 中文 | 痛点卖点、卖点匹配、需求对应、痛点文案 |
| 英文 | pain point matching、value proposition fit |

## 五、输出物说明

**痛点-卖点匹配矩阵 + 文案初稿**

```markdown
| 痛点 | 强度 | 对应功能 | 一句话文案 |
## 缺口（无功能对应）
```

交付前逐条核对：

- [ ] 每条匹配都有具体功能支撑，不是空话
- [ ] 缺口被显式列出，未硬凑

## 六、排错手册

按「症状 → 原因 → 处理」组织。表里的每一条都来自真实使用中撞出来的问题。

| # | 症状 | 原因 | 处理 |
|---|------|------|------|
| 1 | 已知坑（详见 SKILL.md） | 堆砌所有功能是常见错误——只保留能解决强痛点的 | 按上文说明调整后重跑 |
| 2 | 已知坑（详见 SKILL.md） | 痛点来源不同（评论 vs 调研）可信度不同，需标注来源 | 按上文说明调整后重跑 |
