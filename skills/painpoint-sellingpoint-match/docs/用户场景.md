按「谁 → 什么情况下 → 说什么 → 得到什么 → 注意什么」组织。每个场景都能照着跑一遍。

> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · 出海冷启动获客官的日常用法

- **角色**：出海冷启动获客官
- **触发时机**：需要「痛点-卖点匹配」这件事有结果的时候
- **他会说**：`用 painpoint-sellingpoint-match 帮我痛点卖点`
- **需要准备**：痛点清单；产品/服务说明
- **拿到什么**：痛点-卖点匹配矩阵 + 文案初稿
- **容易踩的坑**：堆砌所有功能是常见错误——只保留能解决强痛点的

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 painpoint-sellingpoint-match 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 痛点清单 | ✅ | 缺失会导致输出不可用 |
| 产品/服务说明 | ✅ | 缺失会导致输出不可用 |
| 目标人群 | ⬜ | 有则更好 |
| 竞品对照 | ⬜ | 有则更好 |
